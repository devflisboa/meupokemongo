Como exportar do PokeGenie

  1. 1. Abra o PokeGenie no seu celular
  2. 2. Toque no menu ☰ → Exportar → CSV
  3. 3. Salve o arquivo e transfira para o computador (WhatsApp, cabo USB, Google Drive…)
  4. ⚠ A exportação CSV é recurso do PokeGenie Pro. Sem o Pro, cadastre só os exemplares que importam direto no card (dois cliques → "Adicionar exemplar").
  5. 4. Faça o upload abaixo — o sistema detecta o formato automaticamente

O que é importado?

  • ✓ Todos os Pokémon do seu PokeGenie marcados como capturados
  • ✓ Quantidade por espécie (ex: 3 Bulbasaur = quantidade 3)
  • ✓ Marcação "Para Troca" se qualquer indivíduo estiver marcado no PokeGenie
  • ✓ Cada exemplar com PC, PS, IVs, nível, golpes, sortudo, sombroso/purificado, favorito, peso/altura e rank PvP (Liga Grande, Ultra e Copinha)
  • ✓ Selo 100% automático para exemplares 15/15/15
  • ○ Dê dois cliques em qualquer card para ver todos os detalhes

Nota: A importação atualiza o que você já tem. Pokémon já na coleção terão a quantidade ajustada. A operação é segura e pode ser repetida.
