🤖 Como funciona o modo automático

Um script Python roda no PC conectado ao celular via USB. Ele monitora a tela do Pokémon GO e captura automaticamente cada Pokémon que você abrir — sem precisar tirar print manualmente. Você só navega pelos seus Pokémon; o script faz o resto.

{# Passo a passo #}

1 Instale os pré-requisitos no PC

# Python + bibliotecas
pip install Pillow requests
# Android Platform Tools (ADB)
https://developer.android.com/tools/releases/platform-tools

2 Ative USB Debugging no celular

Configurações → Sobre o telefone → toque 7× em Número da versão → volte para Configurações → Opções do desenvolvedor → ative Depuração USB. Conecte o cabo USB e confirme "Permitir" no celular.

3 Execute o script no PC (terminal)

python scripts/adb_scan.py \
  --url https://meupokemongo.duckdns.org \
  --user SEU_USUARIO \
  --password SUA_SENHA

4 Navegue pelos Pokémon no GO

Abra cada Pokémon que quiser catalogar. O script detecta automaticamente e captura. Você verá o nome e CP confirmados no terminal + uma notificação no celular. Quando terminar, pressione Ctrl+C no terminal.

5 Revise e confirme aqui

Após encerrar o script, volte aqui — o botão "Revisar" vai aparecer com todos os Pokémon capturados para você corrigir e confirmar antes de salvar na coleção.

{# Aviso de limitações #}

⚠ Limitações: a detecção de tela é por heurística de cor — prints muito escuros ou com fundo incomum podem ser ignorados. O script descarta telas que não parecem um Pokémon (mapa, menus, batalhas). IVs só são extraídos da tela de Appraisal.
